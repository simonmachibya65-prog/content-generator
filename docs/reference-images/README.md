## 🎨 Design Insights from Images

### Color Palette
- **Primary Dashboard**: Dark (#0f1117, #1a1f2e) with teal/green accent (#00d4aa)
- **Content templates**: Bold gradients, product-focused, brand colors
- **Analytics**: Clean white cards with colored charts

### Key UI Patterns

#### 1. Dashboard (Lumina360 style - img14)
- Dark background with glowing AI hub in center
- Platform nodes connected with animated lines
- Status badges: Published (green), Scheduled (yellow), Drafting (gray)
- Right sidebar: Performance metrics + Content status donut + Recent activity
- Left sidebar: Navigation + AI Assistant widget at bottom

#### 2. Social Connections (HighLevel style - img1)
- Grid of platform cards (2x4 or 3x3)
- Platform logo + name + Connect/Connected button
- Counter at top: "X of Y accounts connected"
- Green checkmark for connected accounts

#### 3. Content Calendar (ZoomSphere style - img12)
- Weekly view with day columns
- Color-coded post cards (Approved=green, Campaign=blue, To rework=orange, Idea=yellow)
- Platform icons on each card (TikTok, Instagram, Facebook)
- Team member avatars assigned to posts
- Right panel: Platform feed preview (Instagram grid)
- Floating platform icons around the calendar

#### 4. Campaign Dashboard (Adcredo style - img11)
- Dark sidebar with icon-only navigation
- Order pacing line chart (Actual vs Ideal)
- Budget allocation donut chart by platform
- Campaign table grouped by platform
- Status badges: On track, Behind
- Budget progress bars with percentages

#### 5. Analytics (Hootsuite style - img13)
- White card layout with mixed chart types
- Gauge chart for impressions
- Donut chart for post reach by type
- Large % for engagement rate
- Line chart for post performance over time
- Side table for post details (Spend, Impressions, Clicks, CPM, CPC, Conversions)

#### 6. Creative Output Quality
- **Product ads**: Professional studio lighting, brand colors, call-to-action buttons
- **Real estate**: Luxury photography + text overlay + logo + contact info
- **Marketing banners**: Bold typography, diagonal geometric shapes, icons
- **AI images**: Cinema-quality product photography (perfume, serum on marble/rocks)
